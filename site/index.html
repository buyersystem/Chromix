import { launch } from '@xiaoxiaofeihh/chromix';

const browser = await launch();
try {
  const page = await browser.newPage();
  await page.goto('https://example.com');
  console.log(await page.title());
} finally {
  await browser.close();
}

保存为 example.mjs，然后运行 node example.mjs。

04 / GOOD TO KNOW

在 GitHub 提问↗
Chromix 是什么？+

Chromix 是开源的定制 Chromium 浏览器，提供 Python 与 Node.js SDK。它为获得授权的自动化、兼容性测试及研究提供可配置浏览器环境，不是托管浏览器服务。

还能继续使用 Playwright 吗？+

可以。SDK 的 launch 函数返回 Playwright 浏览器对象，可继续使用熟悉的页面和上下文 API。具体参数兼容性与平台限制请查阅 SDK 文档，不应假设所有场景都能无修改替换。

首次启动会下载最新浏览器吗？+

不一定。SDK 根据其配置的下载通道解析版本并缓存，可能与本页展示的发布版不同。需要使用指定本地版本时，将 CLOAKBROWSER_BINARY_PATH 设置为可执行文件的绝对路径，即可跳过下载。

为什么源码与下载版本不同？+

源码版本描述各操作系统当前的构建输入，发布标签则标识一组已发布文件。当前 Linux 与 Windows 源码为 154.0.8037.97，macOS 为 152.0.7977.82。本页指定下载版为 v154.0.8037.57，含六种平台组合的文件。

Docker 镜像现在可用吗？+

本页列出的 ghcr.io/xiaozhou26/chromix:154.0.8037.57 是计划镜像，目标架构为 linux/amd64 与 linux/arm64。本页尚未确认发布完成；使用拉取命令前请查看镜像发布状态，或先使用 SDK 与浏览器构建。

Chromix 保证通过检测吗？+

不保证。浏览器配置能力不等于匿名性、检测绕过或第三方服务的通过率。请仅在获得授权的范围内使用，遵守服务条款与适用法律，并在自己的环境中验证实际行为。
